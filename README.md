# 🌐 Domain Live --- Hosting Landing Page

> A modern neon-themed domain hosting landing page built as a frontend
> UI experiment.

This project is a lightweight single-page landing page designed around a
futuristic hosting/domain activation concept.

It focuses on **visual design, animations, responsive layout, and
interactive frontend effects** using plain HTML, CSS, and JavaScript.

------------------------------------------------------------------------

## ✨ Features

-   🌌 Futuristic neon-themed interface
-   💎 Glassmorphism-style card design
-   🟣 Cyan & purple gradient accents
-   ✨ Animated floating particles
-   🖱️ Interactive cursor glow effect
-   🎬 Floating card animation
-   💡 Neon heading glow animation
-   📱 Responsive layout
-   ♿ Reduced-motion support
-   ⚡ Lightweight vanilla JavaScript
-   🎨 No frontend framework required

------------------------------------------------------------------------

## 🖥️ Preview

The page presents a simulated domain activation/hosting status screen
with:

-   **YOUR DOMAIN IS LIVE** heading
-   Website activation message
-   Hosting status information
-   Server preparation messaging
-   Professional service signature section

The interface is designed to feel like a modern hosting provider's
temporary activation page.

## 🎨 Design Highlights

### Neon UI

The interface uses a dark background with cyan and purple neon accents
to create a futuristic hosting/technology aesthetic.

### Glassmorphism

The main content is presented inside a translucent glass-style card
with:

-   Soft borders
-   Background blur
-   Glow effects
-   Layered gradients
-   Subtle shadows

### Animated Particles

JavaScript dynamically generates floating particles across the page to
add depth and movement to the background.

### Cursor Glow

A custom cursor-following glow creates an interactive visual effect
while the user moves the mouse across the page.

------------------------------------------------------------------------

## 📱 Responsive Design

The layout adapts to different screen sizes, including:

-   💻 Desktop
-   💻 Laptop
-   📱 Mobile
-   📟 Tablet

The project also includes a reduced-motion media query so animations can
be disabled for users who prefer less motion.

## 🚀 Getting Started

No dependencies or package installation are required.

### Clone the repository

``` bash
git clone https://github.com/YOUR-USERNAME/domain-live-landing-page.git
```

### Open the project

``` bash
cd domain-live-landing-page
```

### Run

Open `index.html` directly in your browser.

You can also use **VS Code Live Server** for local development.
